Capabilities

该在云上的活，搬回你自己的机器。

一个 GGUF 文件、一个本地端口、一层客户端外壳。没有账号体系，没有额度，没有「本月已用完」。

全本地推理

权重就在你的存储里，请求不出 127.0.0.1。断网、飞行模式、地下室，照样能聊。

深度思考

Qwen3、R1 蒸馏这些模型先吐 reasoning_content，客户端单独收进一个灰色思考框；Qwen2.5 这类不支持的就自动降级成普通回复，不报错。

联网搜索

输入框边上一个「联网」开关。开了先搜一遍再喂给模型，还要求它在句尾标来源编号。Bing 优先，DuckDuckGo、中文维基三级回退，全部免费无 key。

网页读取 + 截图

把网址丢进输入框，应用会用离屏窗口真实打开它，取回 JS 渲染后的正文并截一张图，正文和截图一起交给模型。页面里没有的信息，它不会编。v1.4.1 起全平台可用。

网页浏览版

同一套界面直接在浏览器里打开，不用装安装包。引擎仍跑在你本机 Termux 或命令行里，网页只连 127.0.0.1。打开网页版 →

人在回路

回复以 CMD: 或 TEXT: 开头分流。命令一定先打印出来，按 y 才执行。rm -rf、mkfs、fork bomb 直接拒绝，连按 y 的机会都不给。

打开就进聊天

启动时扫本地 GGUF，只找到一个就直接用，多个就列出来让你挑；一个都没有，按内存自动推荐档位并下载。8080 被占用就顺延到 8091。

四平台一套协议

Android、Windows 10/11、macOS（Intel 与 Apple 芯片）、Linux。环境变量名完全一致，脚本逻辑也一致，换机器不用重新学。

Quick Start

三步，从空机器到能对话。

推理端归 llama.cpp，客户端归 Harness。两边都不需要注册任何东西。

1

准备 Termux 与依赖

用 F-Droid 或 GitHub 版 Termux，别用 Play 商店那版。装完先更新包列表。

2

拉起 llama-server

模型自己准备，随便一个 GGUF 都行，小模型够用。窗口保持挂着，关了服务就没了。

3

装客户端或跑脚本

不想敲命令行就装 APK / 桌面端；想留在终端里，bash install.sh 一把装好两个命令。

TERMUX
# 依赖 pkg update && pkg install curl jq git cmake
START SERVER
# 中配机上跑，-t 别超过大核数 llama-server -m qwen2.5-1.5b-instruct-q4_k_m.gguf \ -c 1024 --port 8080 -t 4
HARNESS
git clone https://github.com/Huangqia123/termux-ai-harness.git cd termux-ai-harness bash install.sh termuxai # 纯聊天 termuxai-harness # 说人话 → 命令 → 你确认
!
这个版本的 llama.cpp 用的是 --port 而不是 -p。参数写错会直接报 invalid argument，命令根本没起来。

Troubleshooting

跑不起来？大概就这六个原因。

只在本机用就填 http://127.0.0.1:8080/v1。别的设备要通过 WiFi 访问，llama-server 必须监听 0.0.0.0（默认只监听回环），地址换成平板的内网 IP，两边得在同一个局域网，路由器别开 AP 隔离 / 访客隔离。
这是软超时，不是服务挂了。CPU 本地推理慢，客户端等待计时先到点弹了红字，底层数据流其实还在传。把客户端超时调到 90~120 秒，并在请求体里加 "reasoning_effort":"minimal" 缩短思考部分。
KV 缓存塞满了。把 -c 降下来（2048 → 1024 → 512），顺手加 -ctk q8_0 -ctv q8_0 做 KV 量化。平板内存有限，同时开 QQ、浏览器、相册会进一步挤压，后台清干净再跑。
整段对话加起来超过 -c 的额度了。开新对话，或把窗口调到 768。联网模式特别吃 token——搜索回来的网页摘要会直接塞进 prompt，几百 token 一下就没了。
不要紧，忽略它。这是新版 llama.cpp 在做 token 类型检查时的提示性日志，不是崩溃原因。真正让人以为是它导致的 Segfault，多半来自 FlashAttention 在 ARM + Bionic 环境下自动开启。
MagicOS / 各家省电策略把 Termux 后台杀了。电池改成「无限制」，多任务里把 Termux 卡片下拉锁定，再装个 Termux:Boot 顺手搞定开机自启。或者干脆用 tmux 挂着，切走不掉进程。
