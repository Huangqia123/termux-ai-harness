Features

为「真的能用」而设计

不是又一个聊天框套壳。每个决定都围绕一个前提：这台机器可能是你唯一能用的那台。

OFFLINE

全链路 127.0.0.1

推理在本机，请求不出网卡。断网、飞行模式、无 SIM 卡，照常工作。没有账号体系，没有配额，没有「本月额度已用尽」。

GUARD

人在回路

生成的命令先打印出来，按 y 才执行。递归删除、磁盘格式化、关机重启、fork bomb 直接拒绝，连确认机会都不给。

RETRY

失败回灌

命令报错时，把命令原文和输出一起交回模型，让它给出修正版本，最多重试 TERMUX_AI_MAX_RETRY 次。

CROSS

一套逻辑，两种实现

Termux / Linux / macOS 用 bash，Windows 用 PowerShell。接口地址、温度、超时全部走环境变量，两个平台行为一致。

Platforms

你在哪台机器上，都行

Windows 那套是独立实现，不是 bash 套壳——用 PowerShell 原生能力替代 curl 和 jq，不需要装 Git Bash 或 WSL。

平台 脚本 安装 依赖
Termux (Android) bash bash install.sh curl jq
Linux bash bash install.sh curl jq
macOS bash bash install.sh curl jq
Windows 10 / 11 powershell windows\install.ps1 无额外依赖
!

黑名单是模式匹配，不是沙箱。换个写法的破坏性命令仍可能绕过去。它挡的是手滑和模型犯傻，不是恶意构造。执行前请自己看一眼那行命令。

Install

三步，五分钟

先起模型服务，再装工具，最后敲名字启动。模型文件不放进 git——几百 MB 到几 GB 的二进制不该被版本管理。

Termux / Linux / macOS
Windows
# 1. clone
git clone https://github.com/Huangqia123/termux-ai-harness.git
cd termux-ai-harness

# 2. install (Termux pulls curl and jq automatically)
bash install.sh

# 3. start the model server in another window
llama-server -m qwen2.5-1.5b-instruct-q4_k_m.gguf -c 1024 --port 8080

# 4. run
termuxai              # chat
termuxai-harness      # command agent
